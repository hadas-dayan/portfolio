# UI/UX Portfolio Website

## How to Run the Website

### Method 1: Double-Click (Easiest)
1. Go to the Downloads folder
2. Find the file named `index.html`
3. Double-click on `index.html`
4. It will open in your default web browser!

### Method 2: Right-Click
1. Right-click on `index.html`
2. Select "Open with"
3. Choose your web browser (Chrome, Firefox, Edge, etc.)

### Method 3: Drag and Drop
1. Open your web browser
2. Drag the `index.html` file into the browser window
3. The website will load!

## Files Included
- `index.html` - Main website file
- `styles.css` - Styling and design
- `script.js` - Interactive features
- `README.md` - This file

## That's It!
No installation needed. Just open `index.html` in any web browser and your portfolio website will appear!

## Customization
You can edit any of the files to customize:
- Change text, colors, and content in `index.html`
- Modify colors and styling in `styles.css`
- Add more features in `script.js`
